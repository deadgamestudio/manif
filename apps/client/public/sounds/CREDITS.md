# Sound credits

Every file in this folder is **CC0 1.0** (public domain dedication,
https://creativecommons.org/publicdomain/zero/1.0/). No attribution is
required; the sources are listed anyway so anyone can check them. The licence
was checked on each source page itself (Kenney's asset page and the pack's
`License.txt`, the Freesound sound page, the OpenGameArt content page).

All files were cut, peak-normalised (one-shots) or loudness-normalised (loops,
music), mixed down to mono and re-encoded as 32 kHz MP3. Loops had their tail
crossfaded into their head so they repeat without a seam.

Some sounds are not files at all: the hop, the rescue jingle, the countdown
tick, the win fanfare, the sad trombone and the megaphone gibberish are made in
code (`apps/client/src/features/audio/synth.ts`).
